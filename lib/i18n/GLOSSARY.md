# Arabic glossary (approved by MO, 30 Oct 2026)

Style: clear simplified Modern Standard Arabic, with the words staff actually use
(كاش، فيزا، شيفت). Never colloquial sentences. Western digits (123) everywhere.
One English term = one Arabic term across the whole platform.

Keep in English (do not translate): brand/product names (Al Shrooouk / Alshroouk,
El3awama, Paymob, InstaPay is "إنستاباي"), exam/scan type names stored in the
database (3D CBCT, Panoramic, Ceph...), people's names, item names, usernames,
emails, file names, codes, numbers.
